# GPA Hesaplama

Basit ve kullanışlı bir GPA (Genel Not Ortalaması) hesaplama uygulaması.

## Kullanım

- Ders ekleyip sınav ağırlıklarını ve notlarını girin.
- Sınav sonuçlarım sayfasında derslerinizi ve notlarınızı görüntüleyin.
- Transkript sayfasında dönemlik ve genel not ortalamanızı görün.
- Uygulama telefona "Ana Ekrana Ekle" ile kurulabilir ve offline çalışır.
- Veriler tarayıcıda saklanır, tarayıcı önbelleği temizlenmezse kaybolmaz.

## Teknolojiler

- **React 19** - UI kütüphanesi
- **Vite** - Build aracı
- **Tailwind CSS** - Stil
- **vite-plugin-pwa** - PWA desteği (offline çalışma, ana ekrana ekleme)

## Yerel Çalıştırma

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
